YOUR 8 NOVELTY CLAIMS

N1: Two-Error-Mode Framework
Syntactic extraction errors (noisy input) vs semantic verification errors (data rumpang)

N2: Deterministic Admin Grounding
Post-hoc indexed lookup (not RAG, not retrieval). No hallucination risk.

N3: 4-State Confidence Schema
{Verified, Inferred, Unverifiable, Free-form} as first-class output

N4: Null-Honesty Principle
System explicitly reports missing data. Operationalized in training (frozen template) + inference (Unverifiable state)

N5: Data Rumpang as Design Constraint
30% kelurahan null, 34% kodepos null. Not hidden limitation; core architectural feature.

N6: Hybrid Synthetic Corpus
Rule-based admin gap injection + external LLM (syntactic noise only). 230k engineered per two-error-mode taxonomy.

N7: Proof of Sufficiency
8B SLM + deterministic grounding achieves competitive performance at 1000x lower cost than large LLMs

N8: Indonesian-Specific
Jakarta RT/RW + SNI 9037:2021 + Pergub-derived data. Unique to Indonesian governance context.
